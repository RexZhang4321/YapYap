# Archive

Historical working notes from building YapYap. Nothing here is maintained: test
counts, file paths, control names and "pending" items describe the project on the
day each note was written. They are kept as the evidence behind the status claims
in the project README.

| [verification/](verification/) | Point-in-time verification records for individual tasks and migrations. |
